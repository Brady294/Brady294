### Academic Website Platform

A full-stack web application built to manage academic service workflows using a structured production-style setup.

**Core features:**
- User authentication with JWT
- Role-based admin access
- Assignment submission workflows
- File upload functionality
- Pricing based on deadlines
- Payment and deposit logic
- Currency conversion support
- PostgreSQL integration
- Frontend and backend deployment

**Stack:** Next.js, Node.js, Express.js, PostgreSQL, Render, Vercel
